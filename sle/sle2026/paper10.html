SLE 2026 paper:
Enabling Navigability of Programming Language Specifications: A Case of ECMAScript (JavaScript) Standard Library Specification

Alberto Tontoni, Mikhail Barash

  • DOI: 10.1145/3806383.3815524
  • Researchr: details/sle-2026/sle-2026/13/Enabling-Navigability-of-Programming-Language-Specifications-A-Case-of-ECMAScript-J
  • T2E: Documentation
    • The paper’s main object is programming-language specification documentation and how to make it navigable.
  • T5B: Language Description Analysis
    • The paper concerns itself with existing language specs and contemplates how they should be done.
  • T4A: Workbenches
    • IDE twins of specification documents are proposed to be used with language-workbench technology.
  • T3C: DSLs
    • The work introduces a DSL for specifying reusable navigation tasks over specification documents.
  • T5H: Usability
    • The motivation is improving readers’ ability to navigate, query, and understand large language specifications.
