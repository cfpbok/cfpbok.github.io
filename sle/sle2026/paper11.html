SLE 2026 paper:
Dynamic Wind for OCaml Effect Handlers with Escaping Continuation Support

Antonino Yann William Gillard, Tetsuro Yamazaki, Tomoharu Ugawa

  • DOI: 10.1145/3806383.3815525
  • Researchr: details/sle-2026/sle-2026/14/Dynamic-Wind-for-OCaml-Effect-Handlers-with-Escaping-Continuation-Support
  • T4D: Runtime
    • The contribution concerns runtime control-flow behaviour involving delimited continuations, effect handlers, and dynamic scope.
  • T1C: Behavioural Semantics
    • The paper develops semantics for dynamic wind composed with OCaml effect handlers and escaping continuations.
  • T1D: Composition
    • The technical problem is the correct integration/composition of dynamic wind with effect handlers.
  • T3D: GPLs
    • The design and implementation are situated in OCaml, a general-purpose functional programming language.
