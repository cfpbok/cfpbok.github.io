SLE 2026 paper:
Multi-Dimensional Context-Oriented Programming with a Lightweight Domain Specific Language

Christian Gutsche, Sebastian Götz, Uwe Aßmann

  • DOI: 10.1145/3806383.3815517
  • Researchr: details/sle-2026/sle-2026/6/Multi-Dimensional-Context-Oriented-Programming-with-a-Lightweight-Domain-Specific-Lan
  • T1A: Design
    • The paper proposes new language-design mechanisms for multi-dimensional context-oriented programming and context-dependent behaviour.
  • T3C: DSLs
    • The approach is implemented as an embedded DSL in Julia for Contexts.jl.
  • T1D: Composition
    • This behaviour-definition mechanism is based on a composition system for combining context-dependent code fragments.
  • T6F: CPS/IoT/DT
    • The motivating application area is adaptive cyber-physical systems such as autonomous vehicles and smart infrastructure.
