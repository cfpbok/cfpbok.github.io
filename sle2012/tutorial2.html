SLE 2012 tutorial:
A Common Foundational Theory for Bridging Two Levels in Ontology-Driven Conceptual Modeling

Giancarlo Guizzardi, Veruska Zamborlini

  • DOI: 10.1007/978-3-642-36089-3_17
  • Original shorter version of Using a Trope-Based Foundational Ontology for Bridging Different Areas of Concern in Ontology-Driven Conceptual Modeling (SLE 2012 SI)
  • URL: https://www.sleconf.org/2012/Minitutorials.html#giancarlo-guizzardi-and-veruska-zamborlini-a-common-foundational-theory-for-bridging-two-levels-in-ontology-driven-conceptual-modeling
  • T3E: Ontologies
    • The tutorial is centred on foundational ontologies and ontology-driven conceptual modelling (e.g., OntoUML, OWL).
  • T1A: Design
    • The tutorial (re)designs a set of modelling primitives/guidelines grounded in an ontological theory, which is essentially language design work.
  • T4B: Horizontal Transformation
    • A key part is mapping conceptual models to computational codification languages (e.g., OWL), i.e., cross-language conversion.
